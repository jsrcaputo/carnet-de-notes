Politique de confidentialité

Version actuelle — mise à jour le 19 novembre 2026

Document évolutif. Carnet de notes continue d’évoluer. Cette politique peut donc être précisée au fil des nouvelles fonctions. La date ci-dessus indique la version en vigueur. Les protections décrites ici sont déjà appliquées dans la version actuelle de l’application.

En bref : Carnet de notes fonctionne principalement dans le navigateur. Il ne transmet pas les noms, les notes, les commentaires ni les adaptations des élèves à un serveur de l’application.

1. Données utilisées

Le carnet peut contenir des données saisies par l’utilisatrice ou l’utilisateur, notamment :

  • les noms des groupes et des élèves;
  • les niveaux scolaires, adaptations et attentes modifiées;
  • les évaluations, résultats, observations, commentaires et traces d’apprentissage;
  • les préférences d’affichage et certaines pondérations personnalisées.

2. Où ces données sont conservées

Les données du carnet restent d’abord dans la mémoire de l’onglet. Lors de la première sauvegarde, un fichier JSON local peut être choisi puis lié au carnet. Si le navigateur accorde l’autorisation d’écriture, les changements suivants sont enregistrés automatiquement dans ce fichier. Cette liaison peut être retirée dans les options.

Quand la liaison directe n’est pas offerte ou autorisée, l’application télécharge une nouvelle copie JSON et celle-ci doit être conservée manuellement après chaque modification importante. Les exports Excel sont également créés et téléchargés par votre navigateur.

Le carnet n’enregistre plus automatiquement ses données nominatives dans le stockage Web du navigateur. Une ancienne copie peut toutefois rester visible dans les versions précédentes du carnet; elle est alors signalée dans les options afin qu’elle soit téléchargée puis effacée. Quelques préférences sans données d’élèves, comme le thème, l’affichage et certaines pondérations numériques, peuvent rester dans le stockage local du navigateur.

3. Transmission à des serveurs

Le carnet n’envoie pas les données du dossier à un serveur, service d’analyse, outil publicitaire ou modèle d’intelligence artificielle. Aucun système de télémétrie n’est intégré.

Pour les fonctions Excel, certaines bibliothèques techniques peuvent être téléchargées depuis le réseau de distribution jsDelivr. Cette opération sert seulement à obtenir du code d’affichage ou d’export et ne transmet pas le contenu du carnet. Le site contient aussi des liens facultatifs vers des ressources pédagogiques externes; les politiques de ces sites s’appliquent lorsqu’un de ces liens est ouvert.

4. Protection des fichiers

Le carnet peut créer une sauvegarde JSON chiffrée avec un mot de passe, ou protéger un export Excel par mot de passe. La sauvegarde JSON utilise un dérivé de clé renforcé et le chiffrement AES-GCM dans le navigateur. Choisissez un mot de passe robuste et conservez-le séparément : sans ce mot de passe, la sauvegarde chiffrée ne peut pas être récupérée. Le mot de passe n’est ni transmis ni conservé dans le fichier de façon lisible.

Une copie non chiffrée contient les renseignements tels qu’ils ont été saisis. Rangez donc vos fichiers dans un emplacement autorisé, protégez le poste utilisé et évitez de les transmettre à un service en ligne non approuvé.

5. Poste partagé ou emprunté

Avant de quitter un poste partagé, utilisez la fonction Fermer le carnet dans les options. Cette fonction vide le carnet actif, l’historique d’annulation, la liaison avec le fichier, la clé de chiffrement gardée en mémoire et les éléments temporaires d’impression. Fermez ensuite l’onglet.

6. Suppression et maîtrise des données

Vous pouvez modifier ou supprimer les données directement dans le carnet. Pour retirer une copie sauvegardée, supprimez le fichier JSON ou Excel correspondant de l’appareil, de la clé USB ou du service où vous l’avez vous-même placé. Les copies déjà exportées ou imprimées relèvent de votre gestion documentaire.

7. Contact

Pour une question liée au fonctionnement du site ou à cette politique, écrivez à carnetdenotes@duck.com.

8. Règles de l’établissement

Cette politique explique le fonctionnement technique de l’application. Elle ne remplace pas les règles de votre centre de services scolaire, de votre établissement ou votre protocole de gestion documentaire. Utilisez uniquement des emplacements et des pratiques approuvés par votre organisation.

9. Historique des changements

Lorsqu’une fonction modifie la manière dont les renseignements sont enregistrés, sauvegardés ou protégés, cette page sera mise à jour avec une nouvelle date de version.
