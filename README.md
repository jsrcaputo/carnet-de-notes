# carnet-de-notes

Application statique en HTML, CSS et JavaScript : aucun environnement Node.js n'est requis.

Le bandeau temporaire en haut de la page permet de comparer le nouveau design avec la version sauvegardée. Les deux versions gardent leurs données séparément : utilisez **Sauvegarder** puis **Charger** avec le fichier JSON pour transférer un carnet. Pensez à sauvegarder votre travail avant de fermer ou de recharger la page.
